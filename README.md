🌐 Profile Landing Page

A modern, responsive profile landing page built with Next.js, TypeScript, and shadcn/ui, designed to showcase personal identity, skills, and projects in a clean, minimal, and performance-optimized interface.

🚀 Live Demo

🔗 https://profileweb-nine.vercel.app/

✨ Features
⚡ Fast and optimized with Next.js App Router
🧩 Type-safe development using TypeScript
🎨 Modern UI components using shadcn/ui
📱 Fully responsive design (mobile-first approach)
🧑 Profile hero section with introduction and CTA links
🛠️ Skills and tech stack showcase
📂 Project highlights section
🔗 Social links integration
🌙 Clean UI with accessible design system
⚡ Deployed on Vercel for high performance
🛠️ Tech Stack
Framework: Next.js (App Router)
Language: TypeScript
UI Components: shadcn/ui
Styling: Tailwind CSS
Deployment: Vercel

⚙️ Getting Started
1. Clone the repository
git clone <your-repo-url>
cd profile-landing-page
2. Install dependencies
npm install
3. Run development server
npm run dev

Open:
http://localhost:3000

🏗️ Build for Production
npm run build
npm run start
🚀 Deployment

This project is deployed using Vercel.

Steps:

Push code to GitHub
Import repository in Vercel
Deploy with default Next.js settings
